-- Identity comes from the server, not JSON.
getTodo : Pool -> Principal
       -> TodoIdRequest
       -> AppProg FindTodoResponse
getTodo pool principal request = do
  tid <- requireId request.id
  rows pool
    "SELECT id,title,done FROM private_todos WHERE owner_id=$1 AND id=$2"
    [Just principal.subjectId, Just tid]
    >>= found

Can I use Flux in production?+

Not yet. The starter has private owner-scoped tasks, a login UI, durable sessions and verified PostgreSQL TLS. Production HTTPS, deployment operations, backup and restore still need a tested workflow. Treat this as a local multi-user preview.

Is the CLI a hosted platform?+

No. The CLI runs inside the Flux workspace on macOS or Linux. It is development tooling, not a managed cloud or automatic production deployment service. Follow the repository guides for the current local development workflow.
