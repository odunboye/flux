          -> CreateTodoRequest
          -> AppProg TodoView
createTodo repo request = do
  requireTitle request.title
  map wireTodo
    (dbIO (repo.crud.insert
      (MkNewTodo request.title False)))

Can I use Flux in production?+

Not yet. Task endpoints in the demo remain public. Verified PostgreSQL TLS and durable account/session APIs are implemented, but private task ownership, login UI and a production deployment workflow are still ahead. Do not enter private task data.

Is the CLI a hosted platform?+

No. The CLI runs inside the Flux workspace on macOS or Linux. There is no managed cloud, automatic deployment or hot reload. Source changes require a rebuild and restart.
